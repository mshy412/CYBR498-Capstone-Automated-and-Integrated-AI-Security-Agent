# CYBR498-Capstone-Automated-and-Integrated-AI-Security-Agent
AI-powered security reporting agent for small and mid-sized businesses. Uses Python, Bash, cron, and the Anthropic API to collect endpoint logs and security data, then emails easy-to-digest initial, nightly, and weekly reports to authorized staff via a MySQL-controlled list, with a human in the loop. Runs on Ubuntu on-prem or in AWS.
